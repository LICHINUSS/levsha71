# Левша 71

Мастерская игр и приложений «Левша 71». Здесь лежат готовые APK (раздел **Releases**),
каталог для магазина «Лавка Левши» и сайт-витрина: **https://lichinuss.github.io/levsha71/**

## Что где
| Файл | Что это |
|---|---|
| `catalog.json` + `catalog.json.sig` | каталог изделий и **его подпись**. Лавка 2.0+ не примет каталог без верной подписи. После любой правки каталога: `python levsha71-store/tools/sign_catalog.py` |
| `index.html`, `app.html`, `install.html`, `roadmap.html`, `privacy.html` | сайт (RU/EN), страница изделия с историей версий, инструкция с картинками, планы |
| `join.html#КОД` | приглашение в группу: открывает лавку на Android |
| `manifest.webmanifest`, `sw.js` | сайт как приложение на iPhone («На экран „Домой“») и работа без сети |
| `play/brick-tower/` | «Кирпичная башня» для браузера (Godot, без потоков, режим Compatibility) |
| `assets/how/` | рисунки к инструкции (их рисует `levsha71-store/brand/site_how.py`) |
| `assets/fonts/` | шрифт Nunito (OFL) — те же буквы, что в лавке |

`.github/workflows/keepalive.yml` раз в два дня «будит» онлайн-сервер мастерской.

Каждое приложение подписано одним ключом мастерской, поэтому обновления ставятся поверх старых версий.
Отпечаток ключа (SHA-256):

```
90:74:0E:51:42:84:09:08:05:0A:25:25:82:5C:82:CA:54:4B:E6:E3:33:EB:DF:92:95:0C:22:D1:ED:85:F3:1C
```

Подковано Левшой.
