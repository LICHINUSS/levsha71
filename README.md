# Левша 71

Мастерская игр и приложений из Тулы. Здесь лежат готовые APK (раздел **Releases**),
каталог для магазина «Лавка Левши» (`catalog.json`) и сайт-витрина:
**https://lichinuss.github.io/levsha71/**

Что сейчас в мастерской: «Лавка Левши» 1.3.1 (магазин с отзывами, лентой и профилями игроков)
и «Кирпичная башня» 1.1.1 (защита башни из кубиков с рекордами мира).
`.github/workflows/keepalive.yml` раз в два дня «будит» онлайн-сервер мастерской.

Каждое приложение подписано одним ключом мастерской, поэтому обновления
ставятся поверх старых версий. Отпечаток ключа (SHA-256):

```
90:74:0E:51:42:84:09:08:05:0A:25:25:82:5C:82:CA:54:4B:E6:E3:33:EB:DF:92:95:0C:22:D1:ED:85:F3:1C
```

Сделано в Туле. Подковано Левшой.
